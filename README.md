# 🚀 RaiseNow | Modern Crowdfunding Platform

**RaiseNow** is a premium, high-impact crowdfunding application designed to empower individuals and communities to reach their goals. Built with a focus on modern aesthetics, interactive user experiences, and trust-driven features.

> **Note:** This is a **Portfolio Project**. It is a demonstration of modern web development practices, UI/UX design, and complex application architecture. It is not a live financial service.

---

## ✨ Key Features

- **💎 Premium Modern UI**: A high-end visual experience featuring glassmorphism, offset card grids, and smooth micro-animations.
- **🚀 Dynamic Hero Section**: A split-layout banner with real-time growth stats and high-quality campaign imagery.
- **🛡️ RaiseNow Guarantee**: A comprehensive trust-based protection system for donors and beneficiaries, complete with proof-of-trust visual sections.
- **⚙️ "How it Works" Vertical Path**: A sophisticated staggered layout that guides users through the fundraising process with interactive micro-steps.
- **📱 Responsive Excellence**: Fully optimized for desktop, tablet, and mobile viewing with a "mobile-first" approach to interactive elements.
- **🔍 Advanced Discovery**: Real-time search and category filtering to find relevant causes effortlessly.
- **🔄 Smart Navigation**: Enabled scroll-restoration to ensure every page transition starts flawlessly from the top.

---

## 🛠️ Technology Stack

- **Framework**: [Angular 21](https://angular.dev/) (Standalone Components, Signals API)
- **Styling**: [Tailwind CSS v4](https://tailwindcss.com/)
- **State Management**: Angular Signals & RxJS for reactive data handling
- **Typography**: Inter & Custom high-weight black fonts
- **Iconography**: Custom SVG & Lucide-inspired icons
- **Data Source**: Local JSON-based API simulation

## 🚀 Getting Started

### Prerequisites

- Node.js (Latest LTS version recommended)
- Angular CLI (`npm install -g @angular/cli`)

### Installation

1. Clone the repository:
   ```bash
   git clone [repository-url]
   ```
2. Install dependencies:
   ```bash
   npm install
   ```

### Running Locally

1. Start the development server:
   ```bash
   npm start
   ```
2. Open your browser and navigate to `http://localhost:4200/`.

## 🎨 Design Philosophy

RaiseNow was built with the **"WOW"** factor in mind. The design philosophy centers on:

- **Vertical Rhythm**: Using staggered offsets and asymmetrical layouts to guide the eye.
- **Micro-Interactions**: Subtle rotations and glows on hover to make the platform feel alive.
- **Brand Identity**: A clean Green & Pewter color palette that balances professional trust with modern energy.
